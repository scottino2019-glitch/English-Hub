================================================================================
GUIDA RAPIDA & ESEMPI — ENGLISH HUB
================================================================================

Questo progetto usa solo HTML, CSS e JavaScript puro (niente React).
Tutti i file condivisi e le sottopagine si trovano nella cartella "public"
e usano link assoluti (/style.css, /app.js, /pages/..., /assets/...).

--------------------------------------------------------------------------------
1. DOVE MODIFICARE COSA
--------------------------------------------------------------------------------

- index.html
  La Homepage con la griglia Bento. Qui puoi togliere, spostare o aggiungere
  le card dentro <main class="bento-grid"> ... </main>.

- public/style.css
  Unico foglio di stile per tutto il sito (variabili colore, sfondo UK,
  header, griglia Bento, card, bottoni, footer).

- public/app.js
  Unico script per tutto il sito. Gestisce SOLO le parti interattive
  (frasi, quiz, cloze, dialoghi, pronuncia, menu mobile) e NON sovrascrive
  l'HTML di header e footer: puoi modificare qualsiasi tag HTML nelle pagine
  senza rompere il menu o gli altri blocchi.

- public/pages/*.html
  Le pagine separate del sito (ognuna con header e footer HTML diretti):
  * /pages/quiz.html
  * /pages/esercizi.html
  * /pages/dialogo.html
  * /pages/cultura.html
  * /pages/pronuncia.html

- public/assets/images/
  Le immagini locali usate dal sito.

- public/lessons/*.html
  Le lezioni statiche in HTML mostrate nel Manuale di Studio in homepage
  (es. /lessons/lezione-01.html, /lessons/lezione-02.html, ...).

--------------------------------------------------------------------------------
2. COME TOGLIERE UNA CARD DALLA HOMEPAGE
--------------------------------------------------------------------------------

1. Apri il file "index.html".
2. Individua il blocco <article class="bento-card ...">...</article> oppure
   <section class="bento-card ...">...</section> che vuoi eliminare.
3. Cancella tutto il blocco da <article>/<section> fino alla sua chiusura.
4. Salva: la griglia usa "grid-auto-flow: dense", quindi si riadatta da sola
   senza lasciare spazi vuoti, e "public/app.js" ignora senza errori gli
   elementi rimossi.

--------------------------------------------------------------------------------
3. CLASSI PRONTE PER LE NUOVE CARD
--------------------------------------------------------------------------------

Ogni card nella griglia deve avere:
  class="bento-card [COLORE] [DIMENSIONE]"

COLORI & STILI DISPONIBILI:
- card-white          -> Sfondo bianco, testo scuro
- card-slate          -> Sfondo grigio chiarissimo, testo scuro
- card-amber          -> Sfondo giallo crema caldo, testo scuro
- card-emerald        -> Sfondo verde menta chiaro, testo scuro
- card-rose           -> Sfondo rosa chiaro, testo scuro
- card-dark           -> Sfondo blu notte (#0f172a), testo chiaro
- card-quiz-exam      -> Foglio esame puntinato con bordo superiore indaco
- card-cloze-notebook -> Quaderno a righe menta con margine laterale verde
- card-dialogue-chat  -> Finestra stile chat con barra superiore scura
- card-postit         -> Post-it giallo (#fef08a) ruotato con spilla
- card-blog-preview   -> Anteprima articolo rivista con foto laterale
- polaroid-card       -> Polaroid vintage quadrata con didascalia in corsivo

DIMENSIONI DISPONIBILI (su desktop 4 colonne):
- span-1x1      -> Card piccola (1 colonna x 1 riga)
- span-2x1      -> Card media larga (2 colonne x 1 riga)
- span-2x2      -> Card grande quadrata (2 colonne x 2 righe)
- span-4x1      -> Card a tutta larghezza (4 colonne x 1 riga)

5. COME MODIFICARE IL MENU O AGGIUNGERE UNA NUOVA PAGINA
--------------------------------------------------------------------------------

Header e footer sono scritti direttamente in HTML dentro ogni pagina:
puoi aggiungere, togliere o rinominare un link <a href="..." class="nav-link">
direttamente nell'HTML senza dipendere da JavaScript.

Per creare una nuova pagina in "public/pages/" (es. public/pages/verbi.html),
copia la struttura di una pagina esistente (es. "public/pages/cultura.html")
e aggiungi il link <a href="/pages/verbi.html" class="nav-link">Verbi</a>
nell'header delle pagine dove vuoi mostrarlo.

--------------------------------------------------------------------------------
6. COME CAMBIARE COLORI E FONT DI TUTTO IL SITO
--------------------------------------------------------------------------------

Apri "public/style.css" e modifica le variabili dentro ":root { ... }"
all'inizio del file (es. --bg-canvas, --accent-emerald, --accent-amber,
--font-sans, --radius-card). Il cambiamento si applica a tutte le pagine.

--------------------------------------------------------------------------------
7. COME CAMBIARE LINK E INFORMAZIONI DEI VIDEO (CINEMA PLAYER)
--------------------------------------------------------------------------------

Tutti i video della playlist si modificano direttamente in "index.html",
senza dover toccare "public/app.js".

Cerca dentro <div id="video-lateral-list"> i pulsanti <button class="cinema-playlist-item">
e cambia questi attributi:

- data-chapter   -> Etichetta capitolo (es. "Capitolo 01")
- data-title     -> Titolo del video (modificalo anche dentro lo span visibile sotto)
- data-subtitle  -> Sottotitolo descrittivo mostrato sotto lo schermo
- data-duration  -> Durata mostrata (es. "12:45")
- data-thumb     -> Percorso dell'immagine di anteprima (es. "/assets/images/london-mews.jpg")
- data-src       -> Link al video vero e proprio! Supporta automaticamente:
                    * Link YouTube  (es. "https://www.youtube.com/watch?v=...")
                    * Link Vimeo    (es. "https://vimeo.com/123456789")
                    * File .mp4     (es. "/assets/video/lezione1.mp4" o URL esterno)
                    * Vuoto ""      (mostra l'anteprima interattiva con immagine)

Per AGGIUNGERE o TOGLIERE un video dalla playlist, copia o cancella un intero
blocco <button class="cinema-playlist-item">...</button> in "index.html":
il contatore video si aggiorna da solo.

--------------------------------------------------------------------------------
8. COME MODIFICARE ANTEPRIMA BLOG, POLAROID, POST-IT E SMARTPHONE IFRAME
--------------------------------------------------------------------------------

- Anteprima Articolo Blog (.card-blog-preview): cambia l'immagine in
  <div class="blog-preview-thumb">, il titolo, l'estratto e il link href="..."
  del bottone "Leggi l'articolo ->".

- Polaroid Vintage (.polaroid-card): cambia il percorso src="..." dell'immagine
  quadrata dentro <div class="polaroid-photo"> e modifica la scritta a mano in
  basso dentro <div class="polaroid-caption">.

- Post-It Falsi Amici (.card-postit): le voci continuano a scorrere cliccando
  la freccia ->; puoi personalizzare etichette o stile in public/style.css.

- Card Smartphone 9:16 (Iframe): cerca <iframe class="phone-iframe" ...>
  in "index.html". Per caricare un sito o una pagina reale al posto
  dell'anteprima demo, sostituisci srcdoc="..." con src="https://tuo-sito.it".

--------------------------------------------------------------------------------
9. COME AGGIUNGERE O MODIFICARE LEZIONI STATICHE HTML (MANUALE DI STUDIO)
--------------------------------------------------------------------------------

1. Crea o modifica un file HTML dentro "public/lessons/" (copiando la struttura
   di "public/lessons/lezione-01.html" con <article class="lesson-doc">).
2. In "index.html", dentro <div id="lesson-chapters-list">, aggiungi o modifica
   un pulsante:
   <button type="button" class="lesson-chapter-btn"
           data-src="/lessons/lezione-04.html"
           data-title="Lezione 04" data-time="~5 min">
     <span>Cap. IV · Titolo Lezione</span>
     <span>B2 · HTML</span>
   </button>
3. Il lettore carica il file HTML statico automaticamente nel riquadro di lettura,
   aggiorna contatore e pulsanti Prec./Succ. senza dover toccare "public/app.js".
