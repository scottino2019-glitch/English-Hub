================================================================================
GUIDA RAPIDA & ESEMPI — ENGLISH HUB
================================================================================

Questo progetto usa solo HTML, CSS e JavaScript puro (niente React).
Tutti i file condivisi e le sottopagine si trovano nella cartella "public"
e usano link assoluti (/style.css, /app.js, /pages/..., /assets/...).

--------------------------------------------------------------------------------
1. DOVE MODIFICARE COSA
--------------------------------------------------------------------------------

- index.html
  La Homepage con la griglia Bento. Qui puoi togliere, spostare o aggiungere
  le card dentro <main class="bento-grid"> ... </main>.

- public/style.css
  Unico foglio di stile per tutto il sito (variabili colore, sfondo UK,
  header, griglia Bento, card, bottoni, footer).

- public/app.js
  Unico script per tutto il sito. Gestisce SOLO le parti interattive
  (frasi, quiz, cloze, dialoghi, pronuncia, menu mobile) e NON sovrascrive
  l'HTML di header e footer: puoi modificare qualsiasi tag HTML nelle pagine
  senza rompere il menu o gli altri blocchi.

- public/pages/*.html
  Le pagine separate del sito (ognuna con header e footer HTML diretti):
  * /pages/quiz.html
  * /pages/esercizi.html
  * /pages/dialogo.html
  * /pages/cultura.html
  * /pages/pronuncia.html

- public/assets/images/
  Le immagini locali usate dal sito.

--------------------------------------------------------------------------------
2. COME TOGLIERE UNA CARD DALLA HOMEPAGE
--------------------------------------------------------------------------------

1. Apri il file "index.html".
2. Individua il blocco <article class="bento-card ...">...</article> oppure
   <section class="bento-card ...">...</section> che vuoi eliminare.
3. Cancella tutto il blocco da <article>/<section> fino alla sua chiusura.
4. Salva: la griglia usa "grid-auto-flow: dense", quindi si riadatta da sola
   senza lasciare spazi vuoti, e "public/app.js" ignora senza errori gli
   elementi rimossi.

--------------------------------------------------------------------------------
3. CLASSI PRONTE PER LE NUOVE CARD
--------------------------------------------------------------------------------

Ogni card nella griglia deve avere:
  class="bento-card [COLORE] [DIMENSIONE]"

COLORI DISPONIBILI:
- card-white    -> Sfondo bianco, testo scuro
- card-slate    -> Sfondo grigio chiarissimo, testo scuro
- card-amber    -> Sfondo giallo crema caldo, testo scuro
- card-emerald  -> Sfondo verde menta chiaro, testo scuro
- card-rose     -> Sfondo rosa chiaro, testo scuro
- card-dark     -> Sfondo blu notte (#0f172a), testo chiaro

DIMENSIONI DISPONIBILI (su desktop 4 colonne):
- span-1x1      -> Card piccola (1 colonna x 1 riga)
- span-2x1      -> Card media larga (2 colonne x 1 riga)
- span-2x2      -> Card grande quadrata (2 colonne x 2 righe)
- span-4x1      -> Card a tutta larghezza (4 colonne x 1 riga)

--------------------------------------------------------------------------------
5. COME MODIFICARE IL MENU O AGGIUNGERE UNA NUOVA PAGINA
--------------------------------------------------------------------------------

Header e footer sono scritti direttamente in HTML dentro ogni pagina:
puoi aggiungere, togliere o rinominare un link <a href="..." class="nav-link">
direttamente nell'HTML senza dipendere da JavaScript.

Per creare una nuova pagina in "public/pages/" (es. public/pages/verbi.html),
copia la struttura di una pagina esistente (es. "public/pages/cultura.html")
e aggiungi il link <a href="/pages/verbi.html" class="nav-link">Verbi</a>
nell'header delle pagine dove vuoi mostrarlo.

--------------------------------------------------------------------------------
6. COME CAMBIARE COLORI E FONT DI TUTTO IL SITO
--------------------------------------------------------------------------------

Apri "public/style.css" e modifica le variabili dentro ":root { ... }"
all'inizio del file (es. --bg-canvas, --accent-emerald, --accent-amber,
--font-sans, --radius-card). Il cambiamento si applica a tutte le pagine.
